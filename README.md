# static-site

My personal static site.

## Adding private projects

Private projects are listed in the expandable **PRIVATE PROJECTS** section on the projects view. Edit the three `.private-project-card` elements in [index.html](./index.html) with each project's name, description, and category or tech stack. **PROJECT MAYHAM** is a separate expandable project with one description; edit the `.mayham-description` content for it. Keep repository URLs and other private details out of the page.
