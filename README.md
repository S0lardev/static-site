# static-site

My personal static site.

## Adding projects

Private projects are listed in the expandable **PRIVATE PROJECTS** section on the projects view. Public GitHub contributions are listed in the expandable **PUBLIC GIT CONTRIBUTIONS** section, with Project Mayham as the first contribution. Edit the `.private-project-card` elements in [index.html](./index.html) with each project's name, description, and category or tech stack.
